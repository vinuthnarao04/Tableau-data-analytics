## Project Overview

This repository contains the work completed as part of the Deloitte Data Analytics Virtual Experience Program. The project focuses on analyzing business data and creating visualizations to identify useful insights.

## How the Analysis Works

The project includes two main data analysis tasks:
	•	Daikibo Telemetry Analysis: Analyzing machine telemetry data from four factories to identify where machines broke the most and which machines broke most often.
	•	Forensic Technology: Analyzing employee salary data to investigate gender pay equality across different job roles and locations.

## Project Workflow
	1.	Import and examine the provided datasets.
	2.	Clean and analyze the data.
	3.	Identify patterns and key findings.
	4.	Create visualizations and dashboards.
	5.	Present the results as data-driven insights.

## Key Tasks
	•	Machine breakdown analysis using telemetry data.
	•	Factory-wise machine breakdown comparison.
	•	Identification of frequently broken machines.
	•	Gender pay equality analysis.
	•	Salary comparison across job roles and locations.
	•	Data visualization and dashboard creation.
